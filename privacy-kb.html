Privacy Policy · Chuck KB

Whiskey Neat, LLC · Effective 28 October 2026

This policy describes how Chuck KB (the "Application"), operated by Whiskey Neat, LLC, accesses, uses, stores and shares information — including Google user data — when it is authorized. It is separate from the policy for Whiskey Neat Ads Reporting.

Who this applies to

The Application is a personal knowledge-base tool used only by the operator of Whiskey Neat, LLC, on the operator's own mailboxes. It is not offered to the general public, and no one else signs in to it.

What the Application accesses

With the operator's authorization, the Application uses the Gmail API with the read-only scope (gmail.readonly) to read the operator's own mail: message headers (sender, recipients, date, subject) and message text. On first use it reads the previous twelve months; after that, only new or changed conversations. It skips spam, trash, promotional and social mail, newsletters, and password-reset or sign-in-code messages.

The Application does not request access to Drive, Calendar, Contacts, or any other Google service.

Read-only by design

The Application never sends, deletes, archives, labels or otherwise changes any message or setting in Gmail.

How the data is used

Mail is used for one purpose: building a private, searchable index of the operator's own correspondence, so the operator and the operator's AI assistant can find past messages, decisions and context. It is not used for advertising, profiling, selling, or any purpose unrelated to that index, and Whiskey Neat, LLC does not use it to develop, improve or train AI models.

What is stored, and where

The index, including message text, is stored in a database on the operator's own computer. It is not uploaded to any server, website or cloud storage. The OAuth tokens issued by Google are stored on the same computer and are used only to re-authenticate to the Gmail API.

Processing by an AI service

To make long conversations easier to search, the text of a long email thread may be sent to Anthropic's Claude service, under the operator's own Claude account, solely to write a short summary of it. The summary is stored in the same local database. No other service receives Gmail data.

Sharing

Google user data accessed by the Application is not sold, rented, or traded, and is not shared with third parties, advertising networks, data brokers, or analytics providers, except for the summarization described above or where disclosure is required by law.

Retention and deletion

Indexed mail is kept on the operator's computer for as long as the operator chooses, and is deleted by deleting the local database. You can revoke the Application's access at any time from your Google Account permissions page at myaccount.google.com/permissions, which immediately ends its ability to read any further mail.

Limited Use disclosure

The Application's use and transfer of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

Security

The database and tokens are held only on the operator's computer, under the operator's Windows account. The Application's local review screen is served to that computer alone and requires a one-time key.

Changes

If this policy changes, the revised version will be posted on this page with an updated effective date.
