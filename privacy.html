Privacy Policy

Whiskey Neat, LLC · Effective 14 September 2026

This policy describes how Whiskey Neat Ads Reporting (the "Application"), operated by Whiskey Neat, LLC, accesses, uses, stores and shares information — including Google user data — when you authorize it.

Who this applies to

The Application is internal software used by Whiskey Neat, LLC to report on advertising accounts it is authorized to manage. It is not offered to the general public. The only person who authorizes the Application is the operator of Whiskey Neat, LLC, acting on advertising accounts to which they already have authorized access.

What the Application accesses

When you sign in with Google, the Application requests access to the Google Ads API in order to read advertising reporting data from accounts your Google identity can already reach. This includes:

  • Account, campaign, ad group, ad and keyword names and identifiers
  • Performance metrics — cost, impressions, clicks, conversions, conversion value and derived rates
  • Search terms and other reporting dimensions exposed by the Google Ads API

The Application does not request access to Gmail, Drive, Calendar, Contacts, or any other Google service.

Read-only by design

The Application performs reporting queries only. It does not create, modify, activate, pause or delete campaigns, ad groups, ads, keywords, budgets, bids, audiences or conversion tracking. It cannot spend money or change how any advertisement is delivered.

How the data is used

Retrieved advertising data is used for one purpose: producing performance reports and analysis for the advertising accounts Whiskey Neat, LLC manages. It is not used for advertising, profiling, training machine learning models, or any purpose unrelated to reporting on those accounts.

What is stored, and where

The Application stores OAuth tokens issued by Google so that an authorized session persists between uses. These tokens are held in Google Cloud infrastructure (Firestore) within a Google Cloud project controlled by Whiskey Neat, LLC, and are used only to re-authenticate to the Google Ads API.

Advertising reporting data is retrieved on demand and is not retained in a persistent database by the Application. Reports produced from that data may be saved to files or spreadsheets controlled by Whiskey Neat, LLC.

Sharing

Google user data accessed by the Application is not sold, rented, or traded. It is not shared with third parties, advertising networks, data brokers, or analytics providers. Performance reporting derived from a client's own advertising account is shared with that client, and with no one else, except where disclosure is required by law.

Retention and deletion

OAuth tokens are retained while authorization remains active and are removed when access is revoked or the Application is decommissioned. You can revoke the Application's access at any time from your Google Account permissions page at myaccount.google.com/permissions, which immediately ends its ability to retrieve any further data.

Limited Use disclosure

The Application's use and transfer of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

Security

Credentials and tokens are stored in Google Cloud infrastructure with access restricted to Whiskey Neat, LLC. The Application is served over HTTPS and requires Google OAuth authentication before any data can be retrieved.

Changes

If this policy changes, the revised version will be posted on this page with an updated effective date.
